# The Darkness Of The Grasslands

A 2D fighting game built in **Godot 4.7**.

## How to run it
1. Install **Godot 4.7** and **Git** on your PC.
2. Clone the project:
   `git clone https://github.com/Greengrass-Game-coder/The.Darkness.Of.The.Grasslands.repository.git`
3. Open the folder in Godot, let it import, press **F5** to play.

## Working together
- **Before you start:** run `git pull` to get the latest changes.
- **When you're done:** run these three lines:
  `git add -A`
  `git commit -m "what you changed"`
  `git push`
- Always pull before starting. Tell each other before pushing.

That's it. Git handles the rest.
